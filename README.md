# Ciki助手

在源文档页一键剪藏到 Ciki：借浏览器当前的登录态读取正文与附件原图，在插件里转成 ciki 的
TipTap 结构，经你在确认小窗里点头后才写入。另含 ciki 编辑页的「粘贴补抓」：正文里标黄的
未转存图，由插件回源站取原始字节。

开发者模式加载，不上架商店。

## 功能

- **整页剪藏**：标题、正文、代码块、表格、任务列表、引用面板与附件原图一并转存。
- **选空间落位**：确认小窗里选写到哪个空间，父级列表跟着空间走；默认预选上次用过的空间，
  完成后报告里写明落在哪个空间。
- **完成报告**：逐条列出图片转存情况、未转存的原因、只留链接的附件与丢弃的导航宏。
- **粘贴补抓**：在 ciki 编辑页粘贴的图若只有外链地址，插件按 ciki 的请求回源站取原图。
- **逐页手动**：每次都由你点一下触发，不做批量，也不在后台轮询。

## 安装

```bash
pnpm install
pnpm build          # 产出 dist/
```

1. Chrome 打开 `chrome://extensions/`，右上角打开「开发者模式」。
2. 「加载已解压的扩展程序」→ 选本仓库的 `dist/` 目录。
3. 点插件图标 →「设置」完成配置（见下一节）。

## 配置

设置页填三项，点「保存并测试」：

- **源站地址**：你阅读文档的站点地址。填站点根（如 `https://wiki.example.com`）；
  站点路径带 `/wiki` 时填到 `/wiki`。
- **ciki 地址**：如 `https://ciki.example.com`。
- **导入令牌**：在 ciki 的设置页生成后粘贴进来。明文只存在本机
  （`chrome.storage.local`），不随账号同步、不写日志。

保存时 Chrome 会为你填的这两个域名各弹一次授权。插件没有常驻的全站权限，也不读 cookie：
请求只带浏览器当前的会话，和你在同一浏览器里手动打开页面时一模一样；随时可以在
`chrome://extensions/` 的扩展详情里撤销站点访问。

「保存并测试」会真的读一次源站的只读接口与 ciki 的导入接口，两边都通才算配好。

## 使用

- **整页剪藏**：打开要剪藏的源站内容页（保持已登录）→ 标题旁点「剪藏到 Ciki」
  （找不到标题时按钮在右上角；也可以点插件图标再点「剪藏到 Ciki」）。小窗里核对标题、
  选空间与父级（父级列表跟着空间走），遇到同名页选「更新 / 另存 / 取消」，点「开始剪藏」。
  完成页给「在 ciki 打开」与一份完成报告。
- **粘贴补抓**：在 ciki 编辑页粘贴含外链图的内容后，插件自动响应 ciki 的请求，回源站取
  原图字节；成功就由 ciki 在编辑器里替换成图床地址。失败时标黄保留，重试入口在 ciki 的
  图块上，失败原因可以在插件弹窗里看到。

## 开发

```bash
pnpm install        # 安装依赖
pnpm dev            # 扩展页面的开发预览
pnpm build          # 产出 dist/
pnpm typecheck      # 类型检查
pnpm lint           # biome 检查
pnpm test           # vitest
pnpm fixture        # 本地夹具服务，供开发联调
```
